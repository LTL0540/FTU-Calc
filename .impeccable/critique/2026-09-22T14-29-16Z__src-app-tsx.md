# QuantiDerm interface and anatomy critique

Target: src/App.tsx and supporting anatomy, results, patient and schedule components. Operate mode. Heuristic review, not user testing, accessibility certification or clinical validation. No application changes made.

## Design specificity and overall impression

QuantiDerm is product-specific: paired anatomical views, regional presets, FTU/BSA feedback and dispense-versus-calculated-need separation support its actual task. Preserve the calm teal identity. Biggest opportunity: make treatment-area selection simpler than operating a drawing application and keep quantity assumptions visible.

## Strengths

1. Immediate anatomical fill, active-region and numerical feedback establish cause and effect.
2. Complementary entry methods: presets, painter, shared text checklist and explicit handprint override. Preserve keyboard access and Undo.
3. Safety context is integrated with results; invalid inputs block recommendation/copy, and clearing the error restores prior selection.

## Priority issues

### P1 — Keep patient and regimen assumptions visible on mobile

Generic Patient size and Treatment schedule buttons hide current values while the result dock presents an actionable quantity. Default Adult and twice daily for 14 days are not shown beside the quantity.

Fix: editable summaries such as Adult · reference size and Twice daily · 14 days. Repeat abbreviated regimen context in result review. Preserve defaults; do not add unnecessary confirmation steps. Command: $impeccable clarify.

Evidence: src/App.tsx:30,48–51; src/components/AnatomyPainter.tsx:582–586; src/components/MobileResultsDrawer.tsx:43–47; src/styles.css:526.

### P1 — Align anatomy interaction with fixed 20% estimation

Paint suggests freehand lesion marking but selects one of five strips. Clicking a region changes coverage rather than merely opening its inspector; different regions use different strip axes.

Fix: distinguish region inspection from coverage application. Candidate default: select region then affected percentage, retaining zone painting as an expert path. If painting remains primary, call it Mark 20% zones, preview the target and provide immediate percentage feedback. Do not imply spatial precision. Command: $impeccable shape.

Evidence: src/components/AnatomyPainter.tsx:278–292,344–352,470–480,604–606,622–646.

### P2 — Preserve known context when a calculation is blocked

Reproduced: select Face and neck, then enter height 0. Correct error and disabled copy appear, but Selected area becomes 0 FTU / 0% BSA despite the painted selection. Details show 0 applications while retaining 5 adult handprint equivalents. Header incorrectly suggests choosing an area. Clearing height via keyboard restores prior result; state was not lost.

Fix: render known selected area and regimen from input state; render unavailable calculated values as dashes; route recovery to height. This is a presentation/validation-boundary issue, not permission to change clinical constants or calculation rules. Command: $impeccable harden.

Evidence: src/lib/ftuCalculations.ts:9; src/App.tsx:153,331,349; src/components/ResultsPanel.tsx:45–47; src/components/MobileResultsDrawer.tsx:57–59.

### P2 — Group controls and bring coverage editing beside the model

Initial mobile view places eight presets, two settings buttons, six painter controls, explanatory text and view selector before the model. Small-region zoom and coverage controls are below the full-height figure. Mirror both sides can be mistaken for left/right symmetry although it affects front/back.

Fix: group Paint / Fill / Erase, separate Undo / Clear, rename modifier Apply to front + back and associate with view controls. Keep a compact active-region editor near the figure. Presets already collapse after selection: preserve this existing behavior rather than treating it as missing. Commands: $impeccable distill and $impeccable adapt.

Evidence: src/App.tsx:351–353; src/components/AnatomyPainter.tsx:581–618,622–679; src/styles.css:494–519.

### P3 — Refine model silhouette and microtypography

Oval head, thin limbs, mitten hands and joint seams read as a friendly mannequin. Approachable, but less clinically assured than the surrounding calculator. Tiny secondary labels increase effort.

Fix: preserve vector simplicity and brand; improve proportions, hand/foot readability, consistent contour weight; use more legible important secondary labels around 12–14px and quieter noninteractive seams. Avoid photorealism and unsupported anatomical precision. Commands: $impeccable typeset and $impeccable polish.

Evidence: src/components/AnatomyPainter.tsx:142–195,559–569; src/styles.css:393–397.
